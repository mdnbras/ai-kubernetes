# Trabalhar on-premises

Defina distribuição/bootstrap, HA do API server, quorum/backup de etcd, PKI, DNS/NTP, runtime, CNI, CSI, ingress/load balancer e registry. Planeje capacidade física, patches, upgrades, reposição de nodes e disaster recovery com owners claros.
